Numerical conventions & display limits
Values retain the decimal strings exported by SageMath. The digit target is checked by the integrator; it is not a certified error bound. Cut topology and display continuation use float64.
Both banks use the selected geometric orientation. To traverse a sheet boundary, use the positive bank toward ∞ and the negative bank toward 0.
