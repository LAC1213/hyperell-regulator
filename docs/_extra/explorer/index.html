The obstruction ob𝔭(u)

The paper defines ob𝔭(u)=(Qᵤ,(uZ)g(Z)>0), with Qᵤ(γ,δ)=Σ(uZ+uW)γeδe. The positive-genus entries follow the component order in the charge table.

This is a local test for the entered charge. For the divisor charge, the paper's integrality criterion tests membership in this line at every finite place. Adding a constant to u adds the corresponding multiple of ob𝔭(1).

Cycle basis, Laplacian convention and Tate direction

All edges have unit thickness. Thus LZZ=deg(Z) and LZW=−#{edges between Z,W} for distinct components.

The graph is a tree: the cycle pairing is an empty matrix.

We view C as a double cover of ℙ¹ in the integration chart v²=F(u), which is the paper's square model y²=f(x) with coordinates renamed to distinguish it from the LMFDB equation. Using this, we cut up the hyperelliptic curve into two simply connected sheets in order to convert the two-dimensional regulator integral to an integral over the cut. By choosing the cut to be the preimage of a convenient tree Γ in the u-plane, we can moreover choose a path B on the tree as the branch cut for the logarithmic factor of the integrand. With this choice, the integral over the cut simplifies to a bilinear expression of line integrals.

The regulator matrix

The paper's plane-integral matrix R(D₁,D₂), with column factors (Lᴅᵢ,Lᴅⱼ,1) and row weights (1,2 Re(z),|z|²). The rows follow δ₁₁, δ₁₂, δ₂₂. For D=Σ aₚP, Lᴅ(z)=Σ aₚ log|z−u(P)| in the integration chart. The actual values were computed to 100 digits, but we only display 10 digits.
