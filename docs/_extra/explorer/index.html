2. Regulator computation

We view C as a double cover of ℙ¹, using the completed square model v² = f(u). Using this, we cut up the hyperelliptic curve into two simply connected sheets in order to convert the two-dimensional regulator integral to an integral over the cut. By choosing the cut to be the preimage of a convenient tree Γ in the u-plane, we can moreover choose a path B on the tree as the branch cut for the logarithmic factor of the integrand. With this choice, the integral over the cut simplifies to a bilinear expression of line integrals.

3. Beilinson’s conjecture

The numerical verification up to 100 digits of:

π · c⁺(C) · c⁻(C) · L″(Mstd(C), 1) ≈ q · det R(D₁,D₂)

where q is a rational number and c⁺(C) and c⁻(C) are Deligne periods, computed using the path chosen above.
